# ✅ To-Do List

Aplicação de lista de tarefas desenvolvida com HTML, CSS e JavaScript puro, com foco no estudo de manipulação do DOM e lógica de programação no front-end.

## 💻 Acesse o projeto

👉 **[Acessar o projeto](https://luizcvazo.github.io/to-do-list-project/)**

## 📋 Funcionalidades

- [x] Adicionar novas tarefas
- [x] Marcar tarefas como concluídas
- [x] Remover tarefas da lista
- [x] Interface responsiva e limpa

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica do conteúdo
- **CSS3** — Estilização e layout responsivo
- **JavaScript (Vanilla)** — Manipulação do DOM e lógica da aplicação
- **Git & GitHub** — Versionamento e hospedagem via GitHub Pages

## 📂 Estrutura do Projeto

```
├── index.html    # Estrutura da página
├── style.css     # Estilização
├── script.js     # Lógica da aplicação
└── README.md     # Documentação
```

## 🚀 Como executar localmente

```bash
# Clone o repositório
git clone https://github.com/luizcvazo/to-do-list-project.git

# Acesse a pasta
cd to-do-list-project

# Abra o index.html no navegador
```

Ou simplesmente abra o arquivo `index.html` diretamente no navegador.

## 📚 Sobre o projeto

Projeto desenvolvido como exercício de aprendizado em JavaScript, com foco em manipulação do DOM, eventos e lógica de programação no front-end.
